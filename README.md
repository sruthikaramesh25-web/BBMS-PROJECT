# Blood Bank Management System

## Project Overview
The Blood Bank Management System is designed to manage blood donor information, blood inventory, blood requests, and blood distribution efficiently.

## Features
- Donor Registration
- Blood Stock Management
- Blood Request Handling
- Blood Group Tracking
- Hospital Management
- Blood Donation Records
- User Authentication

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP / Python / Java
- Database: MySQL

## Modules
1. Donor Management
2. Blood Inventory Management
3. Blood Request Management
4. Hospital Management
5. Report Generation

## Objective
To automate blood bank operations and ensure quick availability of blood during emergencies.
